# 🇺🇦 Демонстраційний Україномовний Датасет

## Про цей датасет

Це спеціальний демонстраційний датасет для показу можливостей системи аналітики текстів. Оскільки ML-моделі оптимізовані для англійської мови, для української використовуються попередньо підготовлені результати.

## Як це працює

1. **Англійські тексти** → Використовуються справжні ML-моделі (BERT NER, BART Classification, Sentiment Analysis)
2. **Українські тексти** → Показуються демонстраційні результати на основі ключових слів

## Приклади текстів для демонстрації

### 📰 Політика

```
Президент України підписав важливий законопроект про цифрову трансформацію. 
Уряд працює над покращенням економічної ситуації в країні. 
Міністр закордонних справ виступив з позитивною заявою щодо євроінтеграції.
```

**Очікувані категорії:** "Політика (демо)"  
**Ключові слова:** президент, україн, законопроект, уряд, міністр  
**Сентимент:** Позитивний (згадки про покращення, позитивну заяву)

---

### 💻 Технології

```
Компанія Google представила нову технологію штучного інтелекту. 
Український стартап розробив чудову платформу для онлайн-навчання. 
Програмісти створили відмінний додаток для мобільних пристроїв.
```

**Очікувані категорії:** "Технології (демо)"  
**Ключові слова:** компанія, google, технологія, стартап, програміст  
**Сентимент:** Дуже позитивний (чудова, відмінний, нову)

---

### ⚽ Спорт

```
Футбольна команда здобула важливу перемогу в чемпіонаті. 
Спортсмени показали чудові результати на міжнародних змаганнях. 
Тренер виразив позитивне ставлення до гри команди.
```

**Очікувані категорії:** "Спорт (демо)"  
**Ключові слова:** футбольн, команда, спортсмен, тренер, змагання  
**Сентимент:** Позитивний (перемога, чудові, позитивне)

---

### 🏥 Здоров'я

```
Медична реформа покращує доступність послуг для населення. 
Лікарі застосовують нові методи діагностики хвороб. 
Система охорони здоров'я демонструє позитивні зміни.
```

**Очікувані категорії:** "Здоров'я (демо)"  
**Ключові слова:** медичн, реформа, лікар, здоров, система  
**Сентимент:** Позитивний (покращує, позитивні зміни)

---

### 😔 Негативний приклад

```
Економічна ситуація погіршується через погані рішення уряду. 
Населення стикається з проблемами безробіття. 
Експерти висловлюють негативні прогнози щодо інфляції.
```

**Очікувані категорії:** "Загальне (демо)"  
**Ключові слова:** економічн, ситуація, уряд, проблем, негативн  
**Сентимент:** Негативний (погіршується, погані, проблеми)

## Технічні деталі

### Визначення мови
```typescript
private isUkrainian(text: string): boolean {
  const ukrainianChars = /[іїєґ]/i;
  return ukrainianChars.test(text);
}
```

Система шукає українські символи (і, ї, є, ґ) для визначення мови.

### Аналіз сентименту (демо)
- **Позитивні слова:** добре, чудово, відмінно, хороший, позитивн, успіх, радість
- **Негативні слова:** погано, жахливо, поганий, негативн, проблем, помилк

### Класифікація (демо)
- **Технології:** технолог, комп'ютер
- **Політика:** політик, уряд
- **Спорт:** спорт, футбол
- **Здоров'я:** здоров, медицин
- **Загальне:** все інше

### Виділення сутностей (демо)
Система шукає слова з великої літери та інтерпретує їх як організації (ORG).
