# 📝 Швидка Шпаргалка для Демонстрації

## 🎯 Мета
Показати різницю між демо-режимом (українська) та реальними ML-моделями (англійська)

## 📊 Готові файли

### JSON формат (рекомендовано)
- ✅ `demo-dataset-ukrainian.json` - 25 українських текстів
- ✅ `demo-dataset-english.json` - 25 англійських текстів

### CSV формат (альтернатива)
- ✅ `demo-dataset-ukrainian.csv` - 25 українських текстів
- ✅ `demo-dataset-english.csv` - 25 англійських текстів

## ⚡ 3 кроки для демонстрації

### Крок 1: Завантажити датасет
```
1. Відкрити /dataset-upload
2. Вибрати файл (JSON або CSV)
3. Натиснути Upload
```

### Крок 2: Проаналізувати текст
```
1. Вибрати текст з таблиці
2. Натиснути "Аналіз"
3. Почекати завершення
```

### Крок 3: Переглянути результати
```
1. Перейти на /visualization
2. Побачити графіки, хмару слів, категорії
```

## 🇺🇦 Українська - ДЕМО режим

### ✅ Як зрозуміти що працює демо:
- Категорія закінчується на **(демо)**
- Приклад: "Технології (демо)", "Політика (демо)"

### 📋 Тестові тексти:

**Позитивний (Технології):**
```
Компанія Google представила чудову технологію штучного інтелекту
```
→ Категорія: **Технології (демо)**, Сентимент: **позитивний**

**Негативний (Економіка):**
```
Економічна ситуація погіршується через погані рішення уряду
```
→ Категорія: **Загальне (демо)**, Сентимент: **негативний**

**Позитивний (Політика):**
```
Президент України підписав важливий законопроект про цифрову трансформацію
```
→ Категорія: **Політика (демо)**, Сентимент: **позитивний**

## 🇬🇧 Англійська - СПРАВЖНІ ML-моделі

### ✅ Як зрозуміти що працюють ML-моделі:
- Категорія **БЕЗ** слова "(демо)"
- Сутності з типами: PERSON, ORG, LOC
- Точні score для сентименту

### 📋 Тестові тексти:

**Позитивний (Technology):**
```
Google announced a groundbreaking artificial intelligence technology
```
→ Категорія: **Technology**, Сентимент: **positive**, Сутності: **Google (ORG)**

**Негативний (Politics):**
```
Economic situation worsens due to poor government decisions
```
→ Категорія: **Politics**, Сентимент: **negative**

**Позитивний (Sports):**
```
Manchester United secured an outstanding victory in the championship
```
→ Категорія: **Sports**, Сентимент: **positive**, Сутності: **Manchester United (ORG)**

## 🎨 Що показувати в демо

### 1. Хмара слів ☁️
- Візуалізація найчастіших слів
- Розмір = важливість

### 2. Сентимент 😊😐😔
- Позитивний / Нейтральний / Негативний
- Score та comparative

### 3. Категорії 🏷️
- Автоматична класифікація
- (демо) для української

### 4. Сутності 🏢
- Організації, люди, місця
- Тільки для англійської працює BERT

### 5. Ключові слова 🔑
- Найважливіші терміни
- TF-IDF для англійської

## 📊 Порівняльна таблиця

| Функція | 🇺🇦 Українська | 🇬🇧 Англійська |
|---------|----------------|----------------|
| Сентимент | Ключові слова | Sentiment Library |
| Категорії | Правила + "(демо)" | BART Classification |
| Сутності | Великі літери → ORG | BERT NER (ORG/PER/LOC) |
| Ключові слова | Перші 10 слів | TF-IDF |
| Топіки | Розділення слів | LDA |
| Фрази | Перші слова | RAKE |

## 🎬 Сценарій демонстрації

### Варіант 1: Показати обидва режими
```
1. Завантажити demo-dataset-ukrainian.json
2. Проаналізувати текст → показати "(демо)"
3. Завантажити demo-dataset-english.json
4. Проаналізувати текст → показати BERT сутності
5. Порівняти результати
```

### Варіант 2: Тільки демо (українська)
```
1. Завантажити demo-dataset-ukrainian.json
2. Показати різні категорії:
   - Технології (демо)
   - Політика (демо)
   - Спорт (демо)
3. Показати позитивний/негативний сентимент
4. Показати хмару слів
```

### Варіант 3: Тільки ML (англійська)
```
1. Завантажити demo-dataset-english.json
2. Показати точну класифікацію
3. Показати BERT сутності
4. Показати TF-IDF ключові слова
5. Показати LDA топіки
```

## ⚠️ Що пояснити аудиторії

1. **Українська = демо** для демонстрації UI та концепції
2. **Англійська = реальні ML-моделі** для справжньої роботи
3. Позначка **(демо)** чітко показує режим
4. Для production треба тренувати моделі на українській або використовувати англійську

## 💡 Корисні підказки

- Готові датасети вже містять різноманітні приклади
- JSON формат легше читається, CSV компактніший
- У кожному датасеті 25 текстів різних категорій
- Можна завантажити обидва і перемикатися між ними
- Адмін може змінювати ML-параметри через /ml-config

```bash

cd server && npm start

# 2. Запустити клієнт (в іншому терміналі)

# 3. Увійти як адмін

```
