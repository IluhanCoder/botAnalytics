# 📊 Демонстраційні Датасети

## 📁 Файли

- **demo-dataset-ukrainian.json** - український датасет для демо-режиму
- **demo-dataset-english.json** - англійський датасет для ML-моделей

## 🚀 Як використовувати

### 1. Завантаження датасету

1. Відкрийте сторінку **Upload Dataset** (`/dataset-upload`)
2. Натисніть **Choose File**
3. Виберіть один з JSON файлів
4. Натисніть **Upload**

### 2. Аналіз тексту

1. Після завантаження ви побачите таблицю з текстами
2. Натисніть кнопку **Аналіз** біля будь-якого тексту
3. Система автоматично визначить мову:
   - 🇺🇦 **Українська** → демо-режим (hardcoded результати)
   - 🇬🇧 **Англійська** → повні ML-моделі (BERT, BART, etc.)

### 3. Перегляд результатів

Перейдіть на сторінку **Analytics** (`/visualization`) для перегляду:
- 📊 Графіки та діаграми
- ☁️ Хмара слів
- 📈 Аналіз сентименту
- 🏷️ Категорії та сутності

## 🇺🇦 Український датасет (25 текстів)

### Типи текстів:

**1. Загальні повідомлення (10 текстів)**
- Привітання та прощання
- Робочий графік
- Інформація про компанію

**2. Позитивні (10 текстів)**
- Технології: Google, стартапи, програмісти
- Політика: президент, уряд, міністр
- Спорт: футбол, спортсмени, тренер
- Здоров'я: медична реформа, лікарі
- Наука: дослідження, біотехнології

**3. Негативні (5 текстів)**
- Економічні проблеми
- Екологічні занепокоєння
- Негативні прогнози

### Очікувані результати (демо):

- **Сентимент**: базується на ключових словах
  - Позитивні: чудовий, відмінний, позитивн, покращ
  - Негативні: поганий, погірш, проблем, негативн

- **Категорії**: 
  - Технології (демо) - якщо є "технолог", "комп'ютер"
  - Політика (демо) - якщо є "політик", "уряд"
  - Спорт (демо) - якщо є "спорт", "футбол"
  - Здоров'я (демо) - якщо є "здоров", "медицин"
  - Загальне (демо) - все інше

- **Сутності**: слова з великої літери (Google, Україн, Президент)

- **Ключові слова**: перші 10 слів після очищення

## 🇬🇧 Англійський датасет (25 текстів)

### Типи текстів:

Ті самі категорії, що й в українському, але англійською мовою.

### Очікувані результати (ML):

- **Сентимент**: через Sentiment Analysis library
  - Точний розрахунок score та comparative
  
- **Категорії**: через BART Zero-Shot Classification
  - Technology, Politics, Sports, Healthcare, Business, Environment
  
- **Сутності**: через BERT NER
  - PERSON: Manchester United, President
  - ORG: Google, Government
  - LOC: Independence Street
  
- **Ключові слова**: через TF-IDF (natural library)
  - Найбільш значущі терміни з тексту
  
- **Топіки**: через LDA
  - Групування слів за темами
  
- **Фрази**: через RAKE
  - Виділення ключових фраз

## 📋 Приклади для швидкого тестування

### Позитивний український текст:
```
Компанія Google представила чудову технологію штучного інтелекту для обробки текстів
```
**Очікується**: Технології (демо), позитивний сентимент

### Негативний український текст:
```
Економічна ситуація погіршується через погані рішення уряду, населення стикається з проблемами безробіття
```
**Очікується**: Загальне (демо), негативний сентимент

### Позитивний англійський текст:
```
Google announced a groundbreaking artificial intelligence technology for natural language processing
```
**Очікується**: Technology category, positive sentiment, Google as ORG entity

### Негативний англійський текст:
```
Economic situation worsens due to poor government decisions, unemployment problems increase
```
**Очікується**: Politics/Business category, negative sentiment

## 🔍 Як перевірити, що працює демо-режим

1. Завантажте **demo-dataset-ukrainian.json**
2. Проаналізуйте текст з "технолог" або "комп'ютер"
3. У результатах категорія має бути **"Технології (демо)"**
4. Якщо є "(демо)" - працює правильно! ✅

## 🔍 Як перевірити, що працюють ML-моделі

1. Завантажте **demo-dataset-english.json**
2. Проаналізуйте будь-який текст
3. У результатах категорія **БЕЗ "(демо)"**
4. Сутності мають типи: PERSON, ORG, LOC, MISC
5. Якщо немає "(демо)" і є BERT сутності - працює правильно! ✅

## 💡 Поради

- Використовуйте український датасет для **демонстрації** можливостей
- Використовуйте англійський датасет для **реальної роботи** ML-моделей
- Порівняйте результати обох режимів для презентації
- Категорія з "(демо)" чітко показує режим роботи

## ⚠️ Важливо

Демо-режим використовує прості правила та ключові слова. Це **не реальний ML-аналіз**, а заздалегідь визначена логіка для демонстрації інтерфейсу з українськими текстами.

Для реальної роботи використовуйте **англійські тексти**, які обробляються повноцінними ML-моделями!
