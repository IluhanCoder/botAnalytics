# Система стоп-слів

## Як працює

Система стоп-слів тепер використовує **два джерела**:

### 1. Вбудовані стоп-слова (default)
Завжди активні, знаходяться в `server/src/utils/text-processing.ts`:
```typescript
const defaultStopwords = [
  "і", "й", "та", "але", "в", "у", "на", "що", "це", "до", "з", "із", "чи", "як", "за", "бо", "від"
];
```

### 2. Кастомні стоп-слова (з бази даних)
- Додаються адміністраторами через UI
- Зберігаються в MongoDB
- Автоматично завантажуються при старті сервера
- Перезавантажуються після кожного додавання/видалення

## Права доступу

### Адміністратори можуть:
- ✅ Переглядати стоп-слова
- ✅ Додавати нові стоп-слова
- ✅ Видаляти стоп-слова

### Звичайні користувачі можуть:
- ✅ Переглядати стоп-слова
- ❌ Додавати/видаляти (тільки admin)

## API Endpoints

```
GET    /stopword              - отримати всі стоп-слова (доступно всім)
POST   /stopword              - додати стоп-слово (тільки admin)
DELETE /stopword/:id          - видалити стоп-слово (тільки admin)
```

## Як це працює під капотом

### При старті сервера:
1. MongoDB підключається
2. Викликається `loadCustomStopwords()`
3. Стоп-слова з бази завантажуються в пам'ять

### При аналізі тексту:
1. Викликається `analytics/run`
2. Перед аналізом знову викликається `loadCustomStopwords()` (на випадок змін)
3. `preprocess()` використовує об'єднаний список: `[...defaultStopwords, ...customStopwords]`
4. Всі стоп-слова видаляються з тексту

### При додаванні/видаленні:
1. Зміна зберігається в БД
2. Автоматично викликається `loadCustomStopwords()`
3. Нові стоп-слова одразу доступні для наступного аналізу

## Приклад використання

### Сценарій: додати стоп-слово "приклад"

1. **Адмін заходить на `/stopwords`**
2. Вводить "приклад" → "Додати"
3. Слово зберігається в БД
4. Стоп-слова перезавантажуються автоматично
5. При наступному аналізі слово "приклад" буде видалятися з тексту

### Перевірка роботи:

**Текст до обробки:**
```
Це приклад тексту для аналізу
```

**Після preprocess з стоп-словами ["це", "для", "приклад"]:**
```
текст аналіз
```

## Структура файлів

### Server:
- `server/src/utils/text-processing.ts` - логіка фільтрації стоп-слів
- `server/src/stopword/stopword-service.ts` - робота з БД
- `server/src/stopword/stopword-controller.ts` - HTTP endpoints + автоперезавантаження
- `server/src/router.ts` - захист admin-only для POST/DELETE
- `server/src/index.ts` - початкове завантаження при старті

### Client:
- `client/src/stopword/stopwords-mapper.tsx` - UI зі списком + права доступу
- `client/src/stopword/stopword-page.tsx` - форма додавання
- `client/src/stopword/stopword-service.ts` - API виклики

## Важливо! 

Стоп-слова завантажуються **перед кожним аналізом**, тому:
- ✅ Зміни застосовуються одразу
- ✅ Немає потреби перезапускати сервер
- ⚠️ Якщо база недоступна, використовуються тільки default стоп-слова
